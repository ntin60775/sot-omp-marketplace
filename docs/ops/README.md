# Ops

Процедуры обслуживания этого репозитория и выпуска плагинов.

- [Релиз плагина](release-ontoship.md) — тег в репозитории плагина и проверка, что
  он доехал, → bump записи каталога → upgrade у потребителей
- [Обновление потребителей](upgrade-consumers.md) — реестр машины: заведение на новой
  машине, раздача (`check` → `upgrade` → `verify`), снятие плоских копий, частые отказы
- [Bootstrap после свежего клона](bootstrap-after-clone.md) — канон последовательности:
  маркетплейс → установка плагина → проверка → индекс и линтер KB → реестр
  потребителей; отдельно — проверки репозитория
