# Реестр команд и навыков

Этот репозиторий — каталог и KB. Собственного omp-пакета он не несёт: команды и
навыки живут в репозиториях плагинов — `1c-omp` и `ontoship-omp`, и подключаются
из каталога по тегам.

Таблицы ниже генерируются `gitmark inventory` и остаются пустыми ровно потому,
что перечислять здесь нечего. Инвариант I7 (`gitmark lint`) требует, чтобы файл
реестра существовал и таблицы между маркерами совпадали с генерацией, — поэтому
он есть, но без содержимого.
